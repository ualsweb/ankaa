Quick reference

SQL, tables and configuration at a glance.

Table functions and aggregates

FunctionReturns
asof_join(left, right, key [, tolerance_ns [, 'forward']])For every left row, the latest (or next) right row with the same key
ohlcv(table, width_ns [, key])Open, high, low, close, volume, notional and count per bucket
rolling(table, window_ns, step_ns [, key])Bars over a trailing window at every step
percentiles(table, column, 'q1,q2' [, key])Streaming quantiles, 1 % relative error
vwap(price, size)Volume-weighted average price, exact integer sums

Plus all of Apache DataFusion's SQL: joins, window functions, date_bin, CTEs. Rows without a value (NULL) are skipped by every aggregate.

Tables you query

TableContents
<your table>Whatever [[tables]] declares, fed by its [[sources]]
dictionariesNames behind every dict column: table, column, id, name
cq_<name>, cq_<name>_liveClosed and open results of a continuous query
trades, quotes, book_deltas, symbolsThe built-in market-data schema

Column types

timestamp_ns · fixed8 (exact decimal, 8 places) · int64 · float64 · u8 · dict (string to dense id). Any column but the timestamp and dict keys may be nullable.

Configuration skeletonankaad.toml · annotated example
[server]     flight_addr, metrics_addr, pg_addr, token_env, tls_cert, tls_key, tls_client_ca, query_timeout_s
[storage]    wal_dir, checkpoint_dir, snapshot_ms, ingest_coalesce_us, hot_sealed_chunks, warm_budget_mib, market_retention
[resources]  query_memory_mib, memory_budget_mib, memlock_mib
[feed]       enabled, url, streams, depth_snapshots          # built-in exchange feed (optional)
[[tables]]   name, columns, partition_by, max_lateness_ms, retention, max_dict_entries
[[sources]]  name, kind (mqtt|kafka|nats|file), url (mqtt:// or mqtts://), subject, format (json|csv|sparkplug), table, map, rows, ts_unit, tls_ca, tls_cert, tls_key, sparkplug_rebirth
[[continuous]] name, kind (ohlcv|percentiles|rolling|asof), table, key, value, width_ns
[replication] serve_wal, standby_of

$ ankaad config print   # every key with its default
$ ankaad config check   # validate without side effects

# ADR-0003: First data: Binance public feeds and Databento; exchange multicast only with a partner

- **Status:** Accepted 2026-11-09
- **Context:** Review of the previous product definition.

## Decision
Launch dataset is Binance JSON (keyless) and SBE (free API key) full-depth streams plus Databento DBN/live. Exchange multicast decoders (ITCH, MDP 3.0, EOBI) are built only when a design partner provides licensed access.

## Consequences
No market-data licensing cost or paperwork before there are users who need it; the crypto market-maker persona (P1) is the launch persona.
